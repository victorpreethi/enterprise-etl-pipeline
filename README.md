# Enterprise ETL Pipeline (Airflow + BigQuery + GCP)

## Overview
Production-style end-to-end data engineering pipeline designed to simulate enterprise-grade data operations using Apache Airflow, Python, SQL, and Google BigQuery on Google Cloud Platform (GCP).

This project demonstrates automated ETL/ELT workflows, data validation frameworks, CI/CD automation, and scalable cloud data pipeline architecture.

---

## Architecture

- Data Source → CSV / Batch Files
- ETL Engine → Python (Pandas)
- Orchestration → Apache Airflow
- Data Warehouse → Google BigQuery
- CI/CD → GitHub Actions
- Deployment → Docker

---

## Key Features

- Automated end-to-end ETL/ELT pipelines
- Apache Airflow DAG orchestration
- Data ingestion and transformation pipelines
- Data validation and quality checks
- BigQuery integration for scalable analytics
- CI/CD automation using GitHub Actions
- Dockerized development environment
- Production-style logging and error handling

---

## Tech Stack

Python, SQL, Apache Airflow, Google Cloud Platform (GCP), BigQuery, Docker, GitHub Actions, Pandas
